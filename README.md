# E-Parking parking barrier implementation with ESP32

## Hardware Requirements

- ESP32 development board (ESP32-Dev-32)
- Seevo Motor 2PCs(MG995)
- IR Sensor
- Wire

## Libraries Installation
### You need to install all libraries below:

- ArduinoWebsockets.h
- ArduinoJson.h
- ESP32Servo.h
- WiFi.h
